# M1 · 对话播放器

> 先读：`docs/01-任务书.md` 的 §4、§6。前置：M0 已通过。

## 这一阶段只做一件事

把两幕剧情完整演一遍——**战斗先用占位卡代替**，不做战棋。

## 步骤

1. `src/game/state.ts`：定义 `GameState`、初始状态、`reduce(state, action)`；`src/game/router.ts` 管四个 screen 的切换（本阶段只需要 `story`）。
2. `src/game/story/player.ts`：节点执行器。
   - 立即执行：`set`、`jump`、`bgm`、`sfx`、`background`、`hide`、`show`。
   - 等待点击：`stage`、`dialogue`、`inner`、`narration`。
   - 等待选择：`choice`。
   - `end`：当前阶段先跳到一张「第一幕结束」结算页。
   - `call battle_*`：显示一张战斗占位卡（黑底、居中「战斗：battle_prologue_tutorial」「点击继续」），点击后按胜利处理继续往下走。**这是临时实现，M3 会替换。**
3. `src/game/ui/dialogue.ts`：按任务书 §6 做界面——背景、立绘五槽、名字牌、文本框、打字机（30ms/字）、点击/空格/回车推进、选项按钮。
4. 占位：缺立绘的角色画色块 + 首字；缺背景按 `time` 生成渐变 + 场景标题；缺 BGM 静默。
5. `meta: true` 的节点默认跳过；按 `~` 打开开发浮层，显示被跳过的备注、当前场景 id、下一个节点类型。
6. `src/content/overrides.json`：写入三件事——
   - `displayNames`: 序幕内 `怪盗` → `蒙面人`；
   - `a007`: 只启用 index 2；
   - `a010`: index 2 点击后显示说明并回到选项（不跳 A016）。

## 验收

- 从 `P001` 自动开始，一路点击到 `P009`，期间背景/立绘/名字/台词顺序正确，没有把 `【待确认】` 显示给玩家。
- 第一幕 `A001`→`A016` 能走完；`A007` 只有「虚拟主播」能点；`A010` 两项都能点，选「回班上」会弹说明并回到选项。
- 序幕里该角色显示「蒙面人」，第一幕 `A003` 起显示「怪盗」。
- 两个 `CALL: battle_*` 都出现战斗占位卡，点击后剧情继续。
- 控制台 0 error；所有缺失素材只有 `warn`，每个只警告一次。
- `npm run typecheck && npm test && npm run build` 全绿。

## 不许做

- 不许补写任何对白；`【待确认】` 的文本不进玩家视野，但也不许删。
- 不许为了“看起来完整”给没有立绘的角色画 AI 图或找网图。
- 不许实现存档和多周目（M4 再做）。

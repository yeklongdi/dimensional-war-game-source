# 战棋移动规划

> 状态：2026-10-21 已确认，待实现。本轮仅整理说明文档，当前游戏仍是点击目标格直接移动，没有本文件中的路线规划、箭头或终点虚影。
> 工程交接：[movement-preview-spec.md](../工程/movement-preview-spec.md)；决定与理由：[decisions-movement-preview.md](../工程/decisions-movement-preview.md)。

## 目标与范围

为己方角色提供移动前的路线规划，以及移动中的剩余路线提示。只有己方显示箭头与终点虚影，敌人的移动表现保持当前行为。

继续使用 7×5 棋盘、八方向移动、每步 5 尺与不可穿角等现有规则。玩家可以指定必经格，各段之间由系统自动寻路。规划只预览，不扣移动力、不移动角色、不掷骰。

## 基本操作

1. 点击“移动”，显示当前可达格。
2. 悬停合法格子，预览通往该格的路线箭头及终点虚影。
3. 单击格子，将其加入已选路线，成为必须经过的点。
4. 继续悬停其他格子，预览从最后一个已选点出发的下一段；单击后再固定这一点。
5. 点击“确认移动”，按整条已选路线移动。最后一个已点击的格子是实际终点。

**单击格子不再立即移动。** 该决定取代讨论早期的“悬停预览、单击立即执行”，以便添加多个必经点后统一确认。

只悬停、尚未点击的格子不参与执行。鼠标移向确认按钮或焦点离开棋盘时，临时预览段消失，画面恢复为已选路线与已点击终点。

| 操作 | 行为 |
|---|---|
| 确认移动 | 执行已点击确定的路线；至少需要一条合法的非空路线。 |
| 撤回一点 | 删除最后一个已选点，重新计算之前的路线。 |
| 清空路线 | 清除全部已选点和临时预览，保留移动模式。 |
| 取消移动 | 清除规划并退出移动模式。 |
| 键盘聚焦格子 | 与悬停相同，显示临时预览。 |
| 回车或空格激活格子 | 添加必经点，不直接执行移动。 |
| 退格键 | 移动模式下撤回一点。 |
| Esc | 取消规划并退出移动模式。 |

## 路线、落点与预算

箭头沿实际经过格子的中心绘制，使用亮青色与浅色描边，末端箭头表示最后一步方向。已点击的必经格显示小圆点。

终点使用当前棋子的约 35% 不透明度虚影，复用现有圆形标记与名字首字，不复制血条或状态文字。虚影只是落点提示，不是第二个单位，不占格，也不能被攻击或选作目标。

允许绕路和回头，每次经过格子都按实际一步消耗 5 尺；不能用起终点最短距离代替规划路线的费用。

蓝色可达格从最后一个已选点出发，按扣除已规划步数后的剩余移动力计算；没有已选点时从角色当前格出发。临时悬停不会扣除新的规划预算。

无法到达、被占用或超预算的格子不能加入路线，沿用当前提示区域说明原因。无效悬停不延伸路线，无效点击不改变已选点；已有合法路线仍可确认。不自动截短路线，也不替玩家换一条路线。

## 借机攻击符号

可能触发借机攻击的位置，只显示一个小红色感叹号，放在触发路段旁，避开箭头、棋子和终点虚影。

同一敌人在本次规划中只标记首次可能触发的位置。敌人已经消耗反应、失去行动能力或角色处于撤离状态时，按现有规则不标记。

红色符号只表示这一步符合借机条件，不预测是否命中、伤害多少或角色能否最终到达。没有额外风险确认弹窗，路线也不会因为出现符号而自动绕路。

## 移动执行与终止

点击确认后锁定路线，不再接受选点、撤回或修改终点。角色按现有逐格移动内核执行，箭头只保留当前位置之后尚未走完的部分。

借机处理或英雄激励等使移动暂停时，保留剩余路线与终点虚影；规则恢复后继续原路线。到达终点、移动被终止、角色昏迷或死亡时清除箭头和虚影。

切换操作模式、回合变化、战斗重试或离开战斗时，规划也会清除。规划与虚影不写入存档，原场景检查点和战斗刷新行为保持现有约定。

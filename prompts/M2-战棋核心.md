# M2 · 战棋核心

> 先读：`docs/01-任务书.md` 的 §5.1–§5.5、§5.7–§5.9。前置：M1 已通过。

## 这一阶段只做一件事

做出一个**不接剧情**的战斗：通过 `?debug=battle` 直接进入调试场，男高对两个黑衣人，能从头打到结算。

## 步骤

1. `src/game/battle/dice.ts`：`rollD20(rng)`、`rollDamage('1d4+2', rng)`、`advantage/disadvantage`。所有随机走可注入的 `rng`，测试时传固定序列。
2. `src/game/battle/grid.ts`：地图解析（`.` `#` `X` `H` `E`）、`neighbors`、`bfsDistance`、`reachableTiles`、`hasLineOfEffect`（本切片用直线近似即可）。箱子 `X` 不可进入，邻近时提供半身掩护。
3. `src/game/battle/rules.ts`（纯函数，全部可单测）：
   - `attackRoll(attacker, target, {advantage, cover})` → `{total, natural, hit, crit}`；
   - `damageRoll(attack, {crit})` → `{amount, type}`；
   - `applyDamage(target, amount, type)` → 处理临时生命值、抗性、易伤、HP 下限 0；
   - `deathSave(unit, rng)`；
   - `initiative(units, rng)`。
4. `src/game/battle/battle.ts`：战斗状态机。`BattleState = { units, order, turnIndex, round, phase: 'move'|'action'|'bonus'|'end', log }`。所有变更走纯函数，返回新状态 + 日志条目。
5. `src/game/ui/battle-ui.ts` + `render.ts`：
   - Canvas 画棋盘、高亮、单位（圆 + 首字 + HP 条）、掩体箱；
   - 顶部先攻条，当前回合金色描边；
   - 选中己方单位 → 脚下三个按钮 `攻击` `移动` `技能`；技能面板里放 `附赠：徒手` 与 `结束回合`；
   - 右侧战斗日志，每条必须含骰子明细。
6. `src/game/battle/ai.ts`：按 §5.7 实现。
7. 数据：`src/content/combatants.json` 先放三个单位（男高、黑衣人甲、黑衣人乙），字段按任务书 §3.4 的风格自定，但必须含 `abilities/ac/maxHp/speed/attacks/features`。男高缺智力，先写 `int: 10` 并注释「源角色卡未提供」。
8. 入口：`src/main.ts` 读 `location.search`，`?debug=battle` 时跳过剧情直接进战斗；加 `?seed=42` 固定随机数。

## 验收

- `?debug=battle` 能完成一整场：先攻排序 → 移动 → 攻击 → 附赠徒手 → 敌人回合 → 直到一方全灭。
- 日志能看清每一次 `d20+4=17 vs AC12 命中，1d4+2=5，HP 6→1`。
- 借机攻击会触发：男高从黑衣人身边走开时，日志出现一次敌人攻击。
- 掩体生效：站在箱子旁边被打时 AC 显示 +2。
- 死亡豁免能走通：把男高打到 0 会进入昏迷和死亡豁免流程。
- `npm run typecheck && npm test && npm run build` 全绿，测试覆盖 §9 的第 1–5 条。

## 不许做

- 不许把规则写进 Canvas 渲染代码里。
- 不许做技能树、装备栏、法术书。
- 不许用 `Math.random()` 直接散落在逻辑里；一律走 `rng`。

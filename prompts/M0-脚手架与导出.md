# M0 · 脚手架与剧本导出

> 先读：`AGENTS.md`、`docs/01-任务书.md` 的 §2 和 §3。

## 这一阶段只做三件事

1. 建好 Vite + TypeScript 工程。
2. 把剧本与数据复制进 `source/`。
3. 写导出脚本，把两份 Galgame 脚本转成 JSON，并生成缺口清单。

不要写任何界面、不要碰战斗。

## 步骤

1. 初始化工程（当前目录）：`npm create vite@latest . -- --template vanilla-ts`，然后 `npm i -D vitest`。`package.json` 的 scripts 按任务书 §2.3 补齐。
2. 建目录：`docs/`、`tools/`、`source/story/`、`source/data/`、`src/content/`、`src/game/`、`src/tests/`、`public/assets/{portraits,audio,backgrounds,ui}/`。
3. 复制内容。先尝试自己执行（PowerShell）：

```powershell
$vault = 'E:\笔记\次元战争设定'
Copy-Item "$vault\剧情\序幕\序幕_Galgame脚本.md" source\story\prologue.md
Copy-Item "$vault\剧情\第一幕\第一幕_Galgame脚本.md" source\story\act1.md
Copy-Item "$vault\角色\御主\御主：热血男高+saber\角色卡\御主：热血男高+saber.md" source\data\hero.md
Copy-Item "$vault\怪物数据\邪恶组织小弟.md" source\data\org_grunt.md
Copy-Item "$vault\角色\御主\御主：热血男高+saber\图片\热血男高_主立绘.png" public/assets/portraits/hero.png
Copy-Item "$vault\角色\御主\御主：怪盗+（rider）\图片\怪盗 站立 待机.png" public/assets/portraits/thief.png
Copy-Item "$vault\音乐\①史诗氛围包\Homecoming.wav" public/assets/audio/homecoming.wav
Copy-Item "$vault\音乐\①史诗氛围包\缧绁.wav" public/assets/audio/liuxie.wav
```

如果沙箱禁止读取 `E:\笔记\...`，**停下来**，把上面的命令原样打印给用户，等他复制完再继续。不要自己编造剧本内容，也不要从别的目录找替代品。

4. 写 `tools/export-story.mjs`，严格按任务书 §3.2–§3.6：
   - 只解析「第三部分」到「第四部分」之间；
   - 处理多行块、全角冒号、`[占位符]` 标记；
   - 处理 A009 `CHOICE` + `JUMP A010` 与 A010 `OPTION` 的跨场景选项；
   - 把 `【待确认】/【不可执行】/【暂无线性后果】/[变量名待定]/CHECK` 标成 `meta: true`；
   - `SET` 生成 `flag_<幕>_<事件>`；
   - 输出 `src/content/prologue.json`、`act1.json`、`index.json`，并覆盖 `docs/open-questions.md`。
5. 写 `src/tests/export.test.ts`：断言序幕 9 个场景、第一幕 16 个场景、A007 有 4 个选项、存在 `battle_prologue_tutorial` 与 `battle_black_humanoid` 两个 call、所有 `meta` 节点都被标记。
6. 首页只放一个临时统计页：显示「序幕 9 场景 / 第一幕 16 场景 / 警告 N 条」，方便肉眼确认。

## 验收

- `npm run export-story` 能跑通，控制台打印两幕的场景数与警告数。
- `npm run typecheck`、`npm test`、`npm run build` 全绿。
- `docs/open-questions.md` 里能看到：变量名待定、占位素材、`【待确认】` 文本、`random_rd3`。
- 随机抽 3 个场景，JSON 里的台词与 `source/` 原文逐字一致（写个脚本比对，或人工看）。

## 不许做

- 不许改 `source/` 里任何一个字。
- 不许给 `[变量名待定]` 编剧情含义，flag 名只描述“记录了什么”。
- 不许把 `【待确认】` 文本删掉——它要进 JSON 的 `meta` 节点，游戏里隐藏。

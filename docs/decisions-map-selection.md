# 大地图分关选关 · 决策记录

> 日期：2026-10-21。状态：用户已确认，游戏功能与彩绘素材已实现。第9节中的窗口分工是上一轮历史职责，已由本轮明确授权替代；当前实现与验收见第11节及独立验收记录。
> 执行规格：[map-selection-spec.md](map-selection-spec.md)；主日志：[decisions.md](decisions.md)；正式地理：[太阳市地理](../../背景故事/太阳市地理.md)。

## 1. 地图替代整幕卡片

**决定：**主菜单进入太阳市彩绘俯视地图，点击地点，再在右侧选择关卡；通关后直接返回地图。

**理由：**以城市地点组织现有剧情，使关卡推进和回访路线可见。保留 1280×720 逻辑画面及现有播放器、战斗规则，不新增剧情。

## 2. 正式相对地理

**决定：**太阳市为内陆平原城市；北朝上。奶奶家在西侧老住宅区，路口在其东侧，学校位于片区东偏北；仓库经路口向南的支路进入。施工区沿用校园东北角、操场与围墙之间的设定。

**理由：**地图需要明确的地点关系；该组方位已在对话中逐项列出并获用户同意，可以写入正式设定。只固定相对关系，不自行确定公里数、步行时间、新道路名称或校园入口朝向；原校园设施方位继续有效。

## 3. 七关、五节点与原文范围

**决定：**使用 prologue_01–03 与 act1_01–04 七关，边界为 P001–004、P005–007、P008–009、A001–003、A004–008、A009–014、A015–016。使用奶奶家、路口、学校、仓库、施工区五节点，回访复用。

**理由：**25 个开放主场景可以完整分组；教学战及其战后内容留在第二关，幻象与黑色人形战及战后正文留在第六关。地点代表主要事件区域，跨地点场景不删改。三个未完成路线场景仍保留在导出数据，不能作为新关卡开放。

## 4. 顺序解锁与逐步显现

**决定：**只允许进入第一个未完成关，初始仅显现奶奶家与第一关；通关后显现下一关，已完成地点可查看。

**理由：**保持现有主线因果，避免提前暴露未来入口。城市底图可以一直可见，交互标记与关卡列表按进度生成；界面和 reducer 都必须校验，不能用按钮禁用代替规则。

## 5. 已通关关卡不可重玩

**决定：**正式关卡完成后永久禁用进入，可查看完成状态；不提供从旧关或整幕开头重开。当前关失败后的战斗重试保留。

**理由：**这是用户最终确认的要求，取代讨论中曾提出的“保留主线断点再重玩旧关”方案，也取代 M4 的幕头重玩行为。旧 M4 决策与验收保留为历史记录，不再作为新版本重玩依据。已全通关旧档迁移后只能查看完成地图，不为演示新地图自动清档。

## 6. 本关结束与连线

**决定：**完整显示本关最后一句并执行随后自动指令，玩家有效推进后，在进入下一关场景前拦截，记通关并直接回地图。出现下一地点连线、目标高亮与镜头定位，不增加通关确认页。

**理由：**避免抢先执行下一关的文字、演出或 SET。战斗胜利仍回原 CALL 后的位置，完整播放关内后文，不能替代关卡完成。A010 回班说明的原覆盖行为优先，不得误识别为通关。

**决定：**进度线与实际街道分开；同地点对只画一条历史线，按最近推进方向显示箭头；返回奶奶家与学校复用原节点。

**理由：**反向回访需要表达方向而不能反复叠线。动画只表现规则结果，刷新或迁移后直接显示累计进度，不重复补播历史解锁。

## 7. 继续与演出恢复

**决定：**关内退出保留最近场景头检查点；中途看地图不覆盖它。继续时沿用唯一主线的演出重建；战斗中刷新则重播该场景并重新开战。

**理由：**不引入节点级、分支级或战斗中间态存档，继续利用 M4 已验证的恢复能力。跨关仍须继承已有背景、人物和音乐，不能重新执行过去的 SET、文本、战斗或音效。游戏内失败重试保持 M3 语义。

## 8. v2 与只读迁移

**决定：**新增 `dw.save.v2` 保存事件 flag、完成关 ID、时间及地图／关内场景检查点；原 `dw.save.v1` 保留原始字符串。

**理由：**七关完成状态与地图检查点不能继续挤进原五字段含义。版本分离允许校验、迁移和故障回退，不破坏用户原档；有效 v2 优先，坏档与写失败不能伪装成功。

**决定：**旧序幕完成映射前三关完成，旧第一幕完成映射七关完成；其余按保存场景定位，前面关卡完成。若旧档正在重玩已完成内容，取消该检查点并回地图。

**理由：**保留已获主线进度，遵守不可重玩，不把累计战斗胜利误当作关卡完成。全部完成后继续只显示完成地图，多窗口合并不得把检查点退回已完成关。

## 9. 技术与范围约束

**决定：**使用独立地点／关卡配置，原生 DOM、CSS 与 SVG 进度线；底图、标记、文字分层，支持拖动和以指针为中心缩放，相机状态不入档。

**理由：**保持现有工程依赖与规则分层，避免把文字与交互烘焙进图像。地图像素坐标属于美术布局，不等于正式距离设定。

**决定：**本窗口仅新增四份文档、修改任务书、README 与主决策日志；实现代码、地图素材及七关实测交给另一窗口。

**理由：**用户明确划定本窗口职责。原 Excalidraw、M0–M4 历史记录、source、剧情 JSON、自动问题清单及游戏程序保留原样；文档不能提前声称新地图已实现。

## 10. 验收与历史用例

**决定：**实现后保留内容／战斗／恢复回归，补充七关、不可重玩、边界、迁移、多窗口及拖缩测试；先跑三个工程检查，再通过正常操作实际玩完七关，对照 161 段正文。

**理由：**M4 的 170 项通过只证明旧版本。旧“允许重玩”、三卡与 v1 唯一格式的相关测试应按新需求调整并注明依据，不能要求与新规则冲突的断言继续成立；历史验收报告不改写。

## 11. 2026-10-21 · 实现取舍与验证

- 以独立地点／关卡配置组织25场，所有正式入口只接受第一个未完成关；理由：不向剧情JSON写入边界，也不依赖按钮禁用维持不可重玩。关间继续复用既有静默演出重建。
- JUMP／END在进入目标场景之前返回关卡完成结果，由应用reducer原子更新完成前缀和地图检查点；理由：最后一句补全不通关、边界前自动SET不遗漏，A010返回选择优先，两场战斗仍沿用原CALL光标。
- 使用内置imagegen制作1536×1024彩绘底图，选中输出复制到工程；节点按成图建筑落点回填归一化坐标。理由：满足正式相对地理，地图文字／进度线与美术分层，像素不充当正式距离。最终提示词随证据保存。
- 采用共用相机变换、6逻辑像素拖动阈值、适配比例1–3倍缩放、原生节点按钮；理由：拖动不误触、指针锚定缩放和键盘均可验收，不增加运行时库，不把相机写入存档。
- 地图容器用overflow: clip，离屏键盘焦点通过reducer定位；理由：禁止浏览器为聚焦另行滚动容器，确保实际视图只由集中相机控制，指针缩放不因隐藏scrollLeft/scrollTop发生偏移。
- 六次地点推进按无向地点对去重并保留最近方向；最终第七关没有新地点，直接展示静态完成路线。理由：不复制奶奶家／学校节点，不在最终完成时重播上一条解锁线；动画不授予进度。
- v1解码器保留作只读兼容，正式写入仅v2；启动迁移在同源原生锁内重读两键，校验成功且写入成功才提示迁移完成。理由：保留原始串，避免两个窗口互相覆盖或用坏v2静默回退。
- 同源协调锁沿用历史锁名，但新程序的setItem只接受v2键；理由：迁移可与仍在运行的旧M4窗口协调，锁名不是存档写入键。v2建立后有效v2优先，不再从v1反复导入。
- 多窗口合并更长的合法连续前缀与累计true记录，旧关检查点归一化地图；理由：不以时间戳清除进度，不强迫正在播放的旧窗口跳场，后续进入和重复结算幂等。
- 已确认的坏档替换来源和原始串随有效请求跨导航交接；相同坏串的重读不能撤销这次明确确认。理由：立即返回地图后仍可完成一次替换，旧run/revision不写入，也不误覆盖另一窗口新内容。
- 保存失败后的空／有效重读仍保留未保存提示及内存检查点；迁移失败候选可继续内存游玩。理由：读取成功不等于之前写入成功，导航不能抹掉错误反馈或把“继续关卡”变回从头开始。
- 更新M4中三卡、幕头重玩、v1唯一格式和旧窗口退回旧关的冲突断言；保留v1五字段解码测试作为迁移兼容回归。理由：新规格明确替代旧行为，不为保持170项旧断言而留下错误入口；M0–M4历史验收文件不改。
- 受控迁移／存储故障页只替换IO，复用正式控制器和UI；延迟保存由验收按钮释放IO请求。理由：不改真实localStorage、不注入GameState，并可确定性观察确认后的导航交接，避免把计时器调度当作业务规则。
- 七关连续浏览器主线与历史25场／161段逐段对照，两战及M2seed42完整日志对照；异常调度排列另由单测覆盖。理由：区分正常操作实测与受控IO／规则单测，不用构建代替可玩性。详见map-selection-verification.md。

## 12. 2026-10-22 · 铺满窗口与地点选关浮窗

- 决定：地图单独适应浏览器内容区，底图等比铺满，可拖动查看裁掉的边缘；不调用系统全屏。理由：用户要消除地图两侧留黑和常驻右栏，同时保留建筑比例与浏览器操作。
- 决定：点地点后在旁边打开非模态浮窗，点整张当前关卡即可开始／继续。理由：用户选择地点旁浮窗，地图仍可操作，不再通过侧栏中的第二个进入按钮完成选择。
- 决定：初次进入、通关返回、定位当前关卡只定位高亮，浮窗关闭。理由：用户确认必须先点地点才选关，避免旧自动面板延续为自动弹窗。
- 决定：拖缩时浮窗跟随地点，靠边调整并内部滚动，地点锚点移出视野则关闭。理由：用户确认跟随；移出后不留下失去指向的窗口，也不在重新移回时擅自打开。
- 决定：关闭按钮、Esc与点击空白均关闭，键盘打开后聚焦关卡、关闭后返回地点，地图拖动不被当作点击。理由：支持鼠标与键盘，避免误进关与焦点丢失。
- 决定：相机尺寸和浮窗集中在现有状态，纯转换无保存／剧情副作用。理由：保持原存档格式和恢复位置，不能因看地图而覆盖关内检查点。
- 修正：小窗口中浮窗优先让地点可见，并在HUD上下寻找位置；长列表进一步限制高度。理由：浏览器实测发现只按重叠面积加权可能盖住地点或底部控制，改为先保留地点，再避让操作区域。
- 修正：点击边缘露出的地点标签时先将锚点带回视野。理由：标签可点但锚点在窗口外时，不能出现“选中了但没有窗口”。
- 保留：只列已显现关卡，已完成卡片禁用，七关／战斗／存档／美术素材不变。原330项断言不削弱，仅调整旧测试辅助的导航类型以容纳带尺寸参数的新动作。详细结果与发布记录见[独立验收](map-window-verification.md)。

# M4 · 主菜单、关卡选择、存档与全流程验收

> 先读：`docs/01-任务书.md` 的 §6、§7、§10。前置：M3 已通过。

## 这一阶段只做一件事

把四块屏幕串成完整流程，并把验收脚本从头到尾跑通。

## 步骤

1. **主菜单**：标题「次元战争」、副标题「垂直切片」；按钮「开始游戏」「继续」「版本号 v0.1」。「继续」在无存档时置灰。
2. **关卡选择**：三张卡（序幕 / 第一幕 / 第二幕）。悬停放大 1.06 + 金色描边；未解锁卡灰色 + 锁图标；第二幕在通关后显示「已完成垂直切片」但仍不可点。
3. **存档** `src/game/save.ts`：`localStorage['dw.save.v1']`，单槽；在进入场景、选项结算后、战斗结束后写入；「继续」读档并从该场景第一个节点开始。
4. **路由**：`menu → select → story → battle → story → select` 全部走 `router.ts`；任何界面都不许直接改 `screen`。
5. **失败面板**：`重试`、`返回关卡选择`；返回关卡选择不丢已解锁进度。
6. **README.md**：安装、`npm run dev`、`npm run build`、`npm run preview`、已知限制（占位美术、只有两幕、单人队伍）。
7. 跑完 `docs/01-任务书.md` §10 的六步验收，把结果逐条写进 `docs/decisions.md`（哪一步过、哪一步没过、怎么修的）。

## 验收

任务书 §10 六步，一步不差：

1. 主菜单可见，「继续」置灰。
2. 关卡选择：序幕可点，第一幕/第二幕带锁。
3. 序幕 9 个场景走完，P006 战斗打完回到 P007。
4. 序幕通关后第一幕解锁。
5. 第一幕 A007 只有虚拟主播可点；A010「回班上」提示后回到选项；A014 战斗胜利后走到 A016。
6. 第二幕显示「已完成垂直切片」不可点；刷新后「继续」回到最近场景开头。

外加：`npm run build && npm run preview` 打开后同样可玩；控制台 0 error。

## 不许做

- 不许加设置页、音量条、语言切换。
- 不许做多存档槽、云存档、导出存档文件。
- 不许在验收没过的情况下宣布完成。

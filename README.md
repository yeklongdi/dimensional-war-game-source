## 启动与检查

使用现有 Node.js / npm，在工程目录执行：

```powershell
npm ci
npm run dev
```

打开终端输出的地址；默认通常为 `http://localhost:5173/`。正式流程可附加 `?seed=0` 复现战斗。点击、空格、回车推进；文字未显示完时首次操作只补全，下一次才推进。按 `~` 查看开发记录。

本轮生产预览的新档体验入口：[localhost:43842](http://localhost:43842/?seed=0)；直接试移动规划：[独立调试场](http://localhost:43842/?debug=battle&seed=42)。正式验收使用`127.0.0.1:43842`，已全部完成；`localhost:43842`是另一origin，交付时保留在未开始的新档菜单。端口仅在预览服务器运行时有效，可用`npm run preview -- --host 127.0.0.1 --port 43842 --strictPort`重启。

```powershell
npm run typecheck
npm test
npm run build
npm run preview
```

当前验收通过19个测试文件、285项测试及生产构建。移动规划证据见`docs/movement-preview-verification.md`；先前地图版本17文件242项的历史验收保留在`docs/map-selection-verification.md`。仅三个固定开发依赖：Vite 8.3.4、TypeScript 5.9.3、Vitest 5.0.5；无运行时依赖。

## 自动存档与旧档迁移

正式键为 `dw.save.v2`，仅保存 version、原事件 flags、completedLevelIds、地图／关内场景 checkpoint、savedAt。初次空档菜单不写入；首次开始进入地图后自动保存。关内返回地图或菜单保留最近场景头检查点，面板显示「继续关卡」，访问地图不覆盖该检查点。

继续从保存场景的第一个节点开始，重建之前的立绘、背景和 BGM，不播放过去台词、SET、SFX、选择或战斗。在 p006、a014 战斗中退出或刷新，继续时重播场景并重新开战；游戏内失败「重试」仍只恢复本场原 CALL 等待及初始骰序。

`dw.save.v1` 原始字符串始终只读保留：

- 已有有效 v2 优先；损坏 v2 不静默回退覆盖。
- 仅 v2 不存在时校验并迁移 v1。序幕已完成映射前三关完成；第一幕已完成映射七关完成。
- 未完成旧档按场景定位当前关，前面的关视为完成。正在重玩已完成内容的旧检查点取消，回地图定位未完成主线。
- **全通关旧档迁移后只能查看完成地图，不能重玩。** 不为演示地图自动清档。如需从新档体验，可使用另一浏览器资料或独立端口；保留原 origin 的进度。
- 只有成功写入 v2 才提示迁移成功。坏档先保留，明确确认后仅替换 v2；取消不写入，v1 即使损坏也不删除。
- 同源窗口通过原生锁协调，累计 true flag 与更长完成前缀；旧窗口不能把继续位置写回已完成关。当前演出不被另一窗口强制跳走，下一次进入按最新进度校验。
- 读写失败持续显示未保存提示，仍可在当前页面内游玩。主菜单「继续」仅依赖有效存档；内存中的当前关检查点可由地图继续，刷新可能丢失未保存进度。

不同主机、端口或浏览器资料属于不同存储位置，不提供跨设备同步或导入导出。未指定 seed 时每次页面加载生成新 seed；固定 seed 地址可复现，场内重试始终恢复本场初始骰序。

## 剧情、战斗与调试

- A007 四项全部显示，仅导出数据中启用的主播选项可选。A010「回班上」执行原 SET、显示唯一允许的原说明后返回同一选择，不执行原 JUMP a016，也不误判通关。
- SET 即使带 meta 仍记录；CHECK、CAMERA、未知 CG 及制作备注只供开发查看，不解释其中的指令。幻象调用警告一次后继续原文旁白。
- 两战胜利均先回原 CALL 后的光标。p006 后续与 p007、a014 四段战后正文及两个 SET 全部保留，不能打赢即通关。
- 序幕保留三个教学时点及 1 点英雄激励；第一幕保留大师之剑、开场剑痕及 5 点临时 HP。战斗数值、AI、反应和死亡豁免等规则不变。
- 独立调试：`?debug=battle&seed=42`，不读写 v1/v2、不启动剧情或音频。M2 原 seed42 操作仍为第3轮胜利、男高10HP、17次骰子，日志一致。
- 开发服务器的 `/tests/save-storage.html?case=corrupt` 等验收页使用替换存储 IO，不触碰真实 localStorage。迁移、读写故障、竞争及延迟保存可控复现；这些页面不进入生产构建。

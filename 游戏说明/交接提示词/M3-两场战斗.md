# M3 · 两场战斗接进剧情

> 先读：`../游戏说明/工程/01-任务书.md` 的 §5.6、§4.5。前置：M2 已通过。

## 这一阶段只做一件事

把 `CALL: battle_prologue_tutorial` 与 `CALL: battle_black_humanoid` 从占位卡换成真战斗，并接好胜负后的剧情回流。

## 步骤

1. 补齐 `src/content/combatants.json`：男高（两套装备）、黑衣人甲/乙、黑色人形。数值**逐项照抄**任务书 §5.6，不许自行平衡。
2. 写 `src/content/battles.json`：两张地图、出生点、胜利条件、失败条件、教学开关。
3. `player.ts` 里的 `call battle_*` → 切到战斗 screen，把战斗 id 传给战斗模块；战斗结束回传 `{result: 'win'|'lose', flags}`。
4. 胜利：写 `flag_battle_<id>_won`，把 `nodeIndex` 推进到下一个节点，回剧情。
5. 失败：弹出「重试 / 返回关卡选择」；重试 = 用同一份 `BattleState` 初值重开，**不改剧情进度、不扣任何东西**。
6. 序幕教学提示：只在该战斗、且对应时点各出现一次——第 1 回合「点击蓝色格移动」；男高第一次能攻击时「点敌人攻击」；第一次攻击后「还能用附赠动作再打一拳」。用队伍头顶气泡，不用弹窗。
7. 第一幕开场演出：战斗开始前，在棋盘上闪一次金色剑痕（Canvas 画一条 2px 金线 + 200ms 透明度呼吸），然后给男高加 5 点临时生命值，日志写「剑形灼痕共鸣：获得 5 点临时生命值」。
8. 大师之剑按任务书 §5.6 的数据作为男高的武器；附赠徒手仍可独立使用。

## 验收

- 从 `P006` 进战斗，赢或输都试一遍：赢 → 回 `P007` 继续到 `P009`；输 → 重试 → 再赢 → 剧情进度与直接赢完全一致。
- 第一幕 `A014` 进战斗，男高带 5 点临时生命值，日志第一条能看到；赢 → 回 `A015`。
- 战斗里不会出现剧情文本，剧情里不会出现战斗 UI 残留。
- `npm run typecheck && npm test && npm run build` 全绿。

## 不许做

- 不许为了“打起来更爽”改数值、加技能、加血包。
- 不许把失败做成“剧情继续”（第一幕的失败必须是重试）。
- 不许在两场战斗之外再塞别的战斗。

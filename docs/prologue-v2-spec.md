## v4与旧档

磁盘键`dw.save.v4`，容器version4、`contentVersion: prologue_four_parts_v1`；一自动＋六手动，沿用修订、锁、活动运行身份。内部复用v3槽协调器，槽内继续使用v2场景快照，但存储边界只写v4。

v1／v2／v3只读保留，不自动迁移、不读进新版。界面区分有效旧版与坏记录，并提示新版需新开；旧信息不占新版六槽。v4版本／内容版本不符时按坏容器保护，不能回退旧档伪装成功。设置继续用`dw.settings.v1`。

新游戏保留手动档、旧原串及设置；载入较早新版槽恢复其自己的flags及完成前缀，不合并未来进度。场景头恢复、战斗重开、跨窗过期拒绝、锁内重读和失败原子性沿用现有机制。

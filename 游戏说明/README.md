## 分类规则

- 程序、测试、工具、运行素材、原始图片／音频／地图、制作母版和图层数据归代码区。
- 文字设定、任务书、规格、制作说明、验收截图和说明配图归本区。角色卡在这里，原始角色图片在代码区`素材原件/角色`。
- 代码区`source`内的Markdown是正式导出输入副本，保持只读；此处剧情目录是写作原稿。需要换版本时明确导入，再导出检查，不自动把草稿当正式剧情。
- 本轮核验发现四段原稿与正式副本在迁移前已有差异，两边均保持原字节；未判定哪边应覆盖另一边。现有导入器对不同内容的既有副本会拒绝覆盖，这是保护行为。后续更新剧情须先审阅差异并明确授权，不通过目录整理自动同步。
- Obsidian继续使用上一级目录作为仓库；新笔记默认放在本区，新附件默认放在`附件`。编辑器本机设置不上传。
- 依赖、`dist`、本地部署缓存、凭据和机器配置不纳入Git；两区的有效项目内容同步现有仓库，不另建仓库或独立决策日志。

# D&D 2024（5.5E / 5R）属性系统与角色机制

> 来源：玩家手册 2024（Player's Handbook 2024）

---

## 一、六大属性（The Six Abilities）

所有生物——包括玩家角色和怪物——都有六个属性值来衡量其身体和心智能力：

| 属性 | 英文 | 衡量…… | 属性值对应 |
|------|------|--------|-----------|
| **力量** | Strength | 身体力量 | 运动能力、物理出力 |
| **敏捷** | Dexterity | 敏捷性、反应力、平衡感 | 灵活、迅速或安静地移动 |
| **体质** | Constitution | 坚韧程度和耐力 | 努力超越身体的极限 |
| **智力** | Intelligence | 分析能力和记忆力 | 推理与记忆 |
| **感知** | Wisdom | 直觉和与世界的协调程度 | 从环境中察觉事物、洞察行为 |
| **魅力** | Charisma | 自信、仪态以及魅力 | 影响他人、获取好感 |

---

## 二、属性值（Ability Scores）与属性调整值（Ability Modifiers）

### 属性值范围

每个属性都有 1~20 的属性值（冒险者的上限通常为 20），某些效应可使属性值达到最高 30。

| 属性值 | 含义 |
|--------|------|
| 1 | 极低——通常限于怪物，若降至 0 则对应不同效应，视乎是什么导致 |
| 2-9 | 低于常人——存在明显劣势 |
| **10-11** | **常人平均水平** |
| 12-19 | 高于常人——存在明显优势 |
| **20** | 最高——对某类人而言是冒险者的属性值能达到的最高值 |
| 21-29 | 超凡——极度强韧 |
| **30** | 绝巅——属性值能达到的极限 |

### 属性调整值对照表

属性值越高，调整值越大。在进行任何 D20 检定时都要加上对应的调整值。

**公式：调整值 = ⌊(属性值 − 10) ÷ 2⌋（向下取整）**

| 属性值 | 调整值 | 属性值 | 调整值 |
|--------|--------|--------|--------|
| 1 | −5 | 16-17 | +3 |
| 2-3 | −4 | 18-19 | +4 |
| 4-5 | −3 | **20-21** | **+5** |
| 6-7 | −2 | 22-23 | +6 |
| 8-9 | −1 | 24-25 | +7 |
| **10-11** | **+0** | 26-27 | +8 |
| 12-13 | +1 | 28-29 | +9 |
| 14-15 | +2 | 30 | +10 |

> **关键记忆点**：20 属性值 = +5 调整值。这就是你要问的「20 = +5」的由来。

## 三、属性调整值（+5）用于哪些检定？

**+5（20 属性的调整值）** 会加到以下所有相关的 D20 检定中：

### 三类 D20 检定

| 检定类型 | 英文 | 何时使用 | 公式 |
|----------|------|----------|------|
| **属性检定** | Ability Check | 尝试执行可能失败的行动（攀爬、交涉、调查等） | d20 + 属性调整值 + 熟练加值（若熟练） |
| **攻击检定** | Attack Roll | 决定攻击是否命中目标 | d20 + 属性调整值 + 熟练加值（若熟练） |
| **豁免检定** | Saving Throw | 抵抗法术、陷阱、毒素等有害效应 | d20 + 属性调整值 + 熟练加值（若熟练） |

### 属性调整值在各维度上的应用举例

| 属性 | 属性检定用于…… | 攻击检定用于…… | 豁免检定用于…… |
|------|----------------|----------------|----------------|
| **力量** | 强行推动、拉扯、破坏某物 | 近战武器攻击、徒手打击 | 抵抗物理冲击 |
| **敏捷** | 灵巧、迅速或安静地移动 | 远程武器攻击（灵巧武器也可用力量） | 躲开有害效应 |
| **体质** | 努力超越身体的极限 | （一般不直接用于攻击） | 承受毒性危害 |
| **智力** | 推理与记忆 | 法术攻击（智力施法者） | 识破虚假的幻象 |
| **感知** | 从环境中察觉事物、洞察行为 | 法术攻击（感知施法者） | 抵抗精神攻击 |
| **魅力** | 影响、获取好感 | 法术攻击（魅力施法者） | 维持存在感 |

### 详细应用表

| 属性 | 属性检定示例 | 豁免检定示例 |
|------|-------------|-------------|
| **力量** | 强行推开门、举起重物、打破镣铐 | 承受物理冲击、被撞开 |
| **敏捷** | 潜行、走钢丝、撬锁、从高处安全跳下 | 躲开火球术的范围伤害 |
| **体质** | 屏息、长时间行军、抵抗酒精 | 抵抗毒素、疾病、严寒 |
| **智力** | 回忆历史知识、解谜、鉴定魔法物品 | 识破幻术、抵抗心灵控制 |
| **感知** | 察觉隐藏的敌人、追踪足迹、判断谎言 | 抵抗魅惑、恐慌等精神效应 |
| **魅力** | 说服守卫、恐吓敌人、伪装身份 | 抵抗放逐、维持自我存在 |

## 四、熟练加值（Proficiency Bonus，PB）

### 什么是熟练加值？

熟练加值是角色因其训练和专长而获得的额外加成。它反映了角色在某些方面经过训练后的专业水平。

**角色的熟练加值随角色等级的提升而增长**，怪物的熟练加值则随挑战等级（CR）增长。

### 熟练加值表

| 等级 / CR | 熟练加值 | 等级 / CR | 熟练加值 |
|-----------|----------|-----------|----------|
| ≤4 | **+2** | 17-20 | +6 |
| 5-8 | +3 | 21-24 | +7 |
| 9-12 | +4 | 25-28 | +8 |
| 13-16 | +5 | 29-30 | +9 |

### 熟练加值加在哪里？

熟练加值可加在以下地方（前提是你**熟练**于该项）：

| 应用 | 说明 |
|------|------|
| **武器攻击检定** | 使用熟练的武器攻击时，d20 + 属性调整值 + PB |
| **技能检定** | 进行你熟练的技能相关属性检定时 |
| **工具检定** | 使用你熟练的工具时 |
| **豁免检定** | 进行你熟练的豁免（由职业决定：每个职业有两项熟练豁免） |
| **法术 DC** | 计算你施放法术的豁免 DC（8 + 施法属性调整值 + PB） |
| **法术攻击** | 法术攻击检定时，d20 + 施法属性调整值 + PB |

### 不叠加原则

熟练加值不能多次叠加到同一次掷骰中。例如：如果你同时因为两项不同的原因（如技能熟练 + 某个特殊能力）都有资格加熟练加值，你仍然**只加一次**。

**例外——专精（Expertise）**：某些职业特性（如游荡者）提供"专精"，将熟练加值**翻倍**（×2）加到特定检定中。即使翻倍，仍然只应用一份 PB。

技能隶属于某项属性，当你进行属性检定时，若该检定涉及你熟练的技能，则加上熟练加值。

| 技能 | 英文 | 关联属性 | 典型用途 |
|------|------|----------|----------|
| **运动** | Athletics | 力量 | 攀爬、跳跃、游泳 |
| **体操** | Acrobatics | 敏捷 | 平衡、翻滚、体操 |
| **巧手** | Sleight of Hand | 敏捷 | 偷窃、手指灵巧 |
| **隐匿** | Stealth | 敏捷 | 潜行、躲藏 |
| **奥秘** | Arcana | 智力 | 魔法知识、法术识别 |
| **历史** | History | 智力 | 历史事件、古代文明 |
| **调查** | Investigation | 智力 | 搜索线索、推理演绎 |
| **自然** | Nature | 智力 | 动植物、自然环境 |
| **宗教** | Religion | 智力 | 神祇、教义、宗教仪式 |
| **洞悉** | Insight | 感知 | 判断谎言、读取意图 |
| **医药** | Medicine | 感知 | 诊断伤病、稳定伤势 |
| **察觉** | Perception | 感知 | 发现隐藏事物、听觉视觉警觉 |

| **驯兽** | Animal Handling | 感知 | 安抚动物、驾驭坐骑 |

## 六、属性值对衍生数值的影响

| 衍生数值 | 计算公式 |
|----------|----------|
| **护甲等级（AC）** | 基础 AC = **10 + 敏捷调整值**；穿甲时由护甲公式替代 |
| **生命值（HP）** | 升级时：职业生命骰 + **体质调整值**（每级） |
| **先攻（Initiative）** | **敏捷检定** = d20 + 敏捷调整值（必要时 + PB） |
| **近战攻击命中** | d20 + **力量调整值**（或敏捷，若灵巧武器） + PB |
| **远程攻击命中** | d20 + **敏捷调整值** + PB |
| **近战伤害** | 武器伤害骰 + **力量调整值**（或敏捷，若灵巧武器） |
| **远程伤害** | 武器伤害骰 + **敏捷调整值** |
| **法术攻击命中** | d20 + **施法属性调整值** + PB |
| **法术豁免 DC** | 8 + **施法属性调整值** + PB |
| **负重** | **力量 × 15** 磅 |
| **敏捷豁免** | d20 + **敏捷调整值** + PB（若熟练） |
| **体质豁免** | d20 + **体质调整值** + PB（若熟练） |

## 七、完整检定公式汇总

### D20 检定统一公式

```
d20 + 属性调整值 + 熟练加值（若相关且熟练） + 临时加值/减值
```

### 三类检定的目标数值

| 检定类型 | 目标值名称 | 谁设定 |
|----------|-----------|--------|
| 属性检定 | **难度等级（DC）** | DM 根据难度设定，或由规则规定 |
| 攻击检定 | **护甲等级（AC）** | 目标生物的 AC |
| 豁免检定 | **难度等级（DC）** | 导致豁免的效应（如施法者的法术 DC） |

### 典型难度等级（DC）

| 任务难度 | DC |
|----------|-----|
| 非常简单 | 5 |
| 简单 | 10 |
| 中等 | 15 |
| 困难 | 20 |
| 非常困难 | 25 |
| 几乎不可能 | 30 |

## 八、属性值获取方式

在 2024 玩家手册中，属性值可通过以下方式确定：

1. **标准数组**：15、14、13、12、10、8，将这些值分配给你选择的六项属性
2. **购点法**：以 27 点点数分配
3. **随机投掷**：投掷 4d6 取最高 3 个（重复 6 次）

此外，**背景（Background）** 会为三项属性各提供 +2/+1 或 +1/+1/+1 的加值；后续每 4 级获得一次**属性值提升（ASI）** 或选择**专长**（许多专长也会提升属性值 1 点）。

## 九、快速参考卡

| 概念 | 一句话解释 |
|------|-----------|
| **属性值** | 1-30 的数字，代表六大能力的基础强度 |
| **属性调整值** | 由属性值换算（20 = +5），加进所有相关 D20 检定 |
| **熟练加值 PB** | 随等级成长的 +2 ~ +9 加值，体现训练水平 |
| **属性检定** | 尝试做某事的检定：d20 + 属性调整值 + PB（若熟练技能） |
| **攻击检定** | 决定命中与否：d20 + 属性调整值（力/敏/施法属性） + PB |
| **豁免检定** | 抵抗有害效应的检定：d20 + 属性调整值 + PB（若熟练该豁免） |
| **法术 DC** | 8 + 施法属性调整值 + PB |
| **专精 Expertise** | PB × 2，某些职业特性提供 |

# M2 数值来源说明

本轮数据只服务独立 `battle_debug_core`。来源是工程现有只读副本及用户批准的 M2 计划、任务书 §5.6；未重新调查或替换外部规则，也未补写剧情。

## 男高

| 字段 | 值 | 依据 |
|---|---|---|
| 力量 / 敏捷 / 体质 / 感知 / 魅力 | 8 / 15 / 14 / 15 / 8 | `source/data/hero.md` 开头能力值 |
| 智力 | `null` | 原卡未提供；用户明确要求保留未知，不能默认为10 |
| 先攻 | d20+2 | 敏捷15的调整值；任务书序幕表 |
| AC / HP / 速度 | 14 / 10 / 30尺 | AC及HP见原卡，速度与本场数值见任务书序幕表 |
| 徒手 | +4，1d4+2钝击，触及1格 | 原卡武术与熟练+2、敏捷+2；最终数值由任务书固定 |
| 武术附赠 | 攻击动作后徒手一次 | 原卡与本轮确认：未命中也解锁，借机不解锁 |
| 死亡豁免 | 玩家专用 | 本轮确认的死亡、稳定、苏醒和补刀规则 |

JSON 的攻击 `bonus: 4` 已经包含熟练与敏捷，不在执行时再加。智力未参与本场任何检定。未实现英雄激励、大师之剑或开场临时HP。

## 黑衣人甲、乙

基础能力参考 `source/data/org_grunt.md` 中邪教徒：力量11、敏捷12、体质10、智力10、感知11、魅力10，AC12、速度30尺。本场采用任务书批准的弱化值，不能用原怪物覆盖：

| 字段 | 原怪物 | M2 调试场 |
|---|---|---|
| HP | 9 | 甲乙各6 |
| 近战攻击加值 | +3 | +2 |
| 近战伤害 | 1d6+1挥砍 | 1d6挥砍 |
| 黑暗忠诚 | 有 | 无 |
| 远程金属装置 | 原卡无 | 仅乙：+2，1d6穿刺，常规4格/最大12格；来源为任务书序幕表 |

两名敌人先攻均为d20+1。零血直接击败，不投死亡豁免。乙的 `prefer_ranged` 只是任务书指定的AI偏好，不增加能力或检定。攻击 `bonus: 2` 同样是最终加值。

## 地图与文件边界

`src/content/combatants.json` 仅三名单位；`src/content/battles.json` 仅下列正式调试地图，出生顺序为男高、甲、乙：

```text
.......
..X....
H...X..
.....E.
......E
```

每格5尺；`X` 为不可进入但不阻断攻击的箱子。地图来自任务书序幕表。本场id为 `battle_debug_core`，没有覆盖剧情中的 `battle_prologue_tutorial` 或 `battle_black_humanoid`。

内部反应页仅将同一套单位临时放在男高(1,2)、甲(2,2)、乙(6,4)，沿用正式地形；骰序为 `[1,20,1,13,2]`，甲先行动并合法走到(4,3)。该设置位于 `src/tests/fixtures/reaction-browser.ts`，不写入正式内容JSON，不进入生产构建。

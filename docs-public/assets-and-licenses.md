# 样例素材与许可边界

## 本仓库实际包含

- public-demo/assets/maps/demo-map.svg：为说明地图资源接入而制作的抽象几何占位图，不表示真实城市地理。
- public-demo/assets/portraits/demo-actor.svg：界面资源绑定示例用的几何占位图，不表示正式角色。
- samples/story/：用于解析和播放器演示的合成文本，不属于《次元战争》正式剧情。
- src/content/ 中随仓库提交的 JSON：中性测试单位、演示关卡和示例音频映射配置，不属于正式游戏设定。

这些演示文件由本仓库维护者为技术演示编写，并按 README 中明确列出的范围随 MIT 许可提供。它们不可用作正式游戏素材或正式内容来源。

## 不随本仓库发布

正式剧本副本、角色卡和设定、正式战斗单位与关卡数据、原立绘、彩绘城市底图、两首 WAV 音乐、内部验收截图、参考作品截图和来源／再分发许可不明确的任何媒体均未纳入。曾可经网站访问不构成再分发许可。

没有复制第三方字体或素材；界面使用系统字体回退。若后续贡献第三方资源，必须先确认再分发授权并保留原有许可、版权标记和署名。
